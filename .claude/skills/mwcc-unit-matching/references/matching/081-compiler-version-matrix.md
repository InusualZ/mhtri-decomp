# 81. Compiler-version matrix

**Problem.** "The original used a different compiler release" is the first suspicion and has to be closed once, per unit.

**Why it does not work.** Compile the matrix once for the unit; if it is flat, version is not the lever. (Playbook 17 covers the one case where the version *is* the lever: a prebuilt SDK unit from another family.)

**Result.** Old table status: no.
