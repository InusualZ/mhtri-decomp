## Method (one implementation: `tools/splits/dataattach.py`, selftest `--selftest`)

* **Runs.** The unowned data symbols between two owners; the 4 recut-run assignments of the phase 1 default (data-by-reader: `lobby/fn_8021E1EC`
  `.data`/`.bss`, `Pl/fn_80288CEC` `.bss`/`.sbss`) count as unowned again and are replaced by rows (the renderer then skips the default for them).
* **Candidate owners of a run** = the previous and the next owner and every unit with `.text` between them (data follows text, the `order` invariant);
  a text-less owner (a registered data-only unit such as `Pl/pl_frame_data`) has no text position, so the text units between the nearest *text*
  owners count.
* **Monotone assignment.** Symbols in address order get non-decreasing owners; score = weight for every unit that references the symbol and owns it:
  a text reader decoded from the retail text (signals 1, 5), a literal only by a load (3), a table of code pointers also references the units it
  points into (4), a global written by the unit's own `__sinit` counts four times, a `scope:local` symbol weighs 3, a jump table 5 (6).
  Solved twice: **A** soft, **B** with the checker's hard rules (a jump table in the unit that reads it, a local bss object in a unit that reads it,
  a vtable in a unit holding a slot or storing it, a strong zigzag seam is a unit edge; a minimal contradicting set is given up, vtable first).
  A symbol is **decided** only when every optimal assignment of A *and* B gives it the same owner; otherwise it is **ambiguous** and goes to
  `unowned_data` with its candidates. A pool block that goes down in first-use order inside one owner is cut back to its longest in-order stretch.
* **Grades.** `strong`: both ends of the row are symbols referenced by that unit alone and no symbol of the row is referenced only by other units;
  `medium`: decided by the optimum alone (shared symbols, or a symbol only other units read, sit inside the row: reported as signal 0 / -1).
  No `guess` row exists: a guess is `unowned_data`, never applied.
