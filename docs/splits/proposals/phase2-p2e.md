## Method (every number is reproducible with `splitcheck.py --proposal ... --readers SECTION:START-END`)

1. **Run and candidates.** An unowned run is the stretch of one section between two owners; its candidate owners are the candidate's units between them in text order (`prev` and `next` included; a data-only
   unit is placed by the first reader of its data). Span 2 = the run can only grow its neighbours; span 3+ = interior units can take it.
2. **Evidence per symbol** (readers decoded from the retail `.text`; a numeric `.sdata2` literal only by a load): D = the units whose text reads it; I = the units that read a table pointing at it (data words, 3 rounds); F = the units owning
   functions a table points at. **A monotone DP** over the candidates (data follows text order inside one section) minimises, lexicographically, 1000 x readers outside the unit, 10 x indirect, 1 x function-pointer misfits;
   forward/backward costs give every symbol the interval of units that some optimal assignment gives it. An interval of one unit = decided; a wider one = **ambiguous** (the cut is somewhere in the stretch).
3. **Signals** (the brief's numbering): 1 = read by the unit (sole reader, or shared with units that cannot take the range); 1p = reached only from a table of the unit; 3 = pool literal in first-use order (numeric `.sdata2`);
   4 = vtable stored by the unit; 5 = `.bss`/`.sbss` object read by the unit (follows the text order); 6 = jump table of a unit function; 7 = `__FILE__` string; 8 = contiguity: no evidence of its own, between two symbols of the unit
   (link order); 8x = contiguity against its readers (read only by other units, between two symbols of the unit). 2 (data-order seam) and the `ctors` closure (signal 4 by the sinit) never decided a symbol in this window: the seams only *refute*
   (below).
4. **Grade** of a block (consecutive symbols of one unit): S = symbols read by the unit, X = symbols read only by a unit the run could also give the range to (counter-evidence), U = read only by units outside the run's candidates (no information).
   `strong` = X 0, S >= 2, U <= S; `medium` = X 0 and S 1, or S >= 3X; anything else (**weak**) is not attached: it goes to `unowned_data` with the DP owner first.
