# `lib/cextract` - A one-function translation unit from a C/C++ file

## Purpose

Builds the probe TU `mwcc_debugger.py --extract` (and its fallback) compiles instead of a whole unit: the file's
preamble, types and declarations, one function's definition, and every other function reduced to a declaration or
dropped. Removed text is blanked with its newlines and preprocessor lines kept, so every line keeps its number and
every `#if` its partner.

## Users

`tools/mwcc-debugger/mwcc_debugger.py` (generated by `make_port.py`: `extract_unit`), `tools/mwcc-debugger/extract.py`
(the standalone CLI).

## Public API

* `extract(text, function) -> Extraction(text, kept, whole, stubbed, dropped)`: each list holds `name@line` of the
  top-level definitions (not inside a class body or another definition) the rewrite kept (the target), kept whole
  (`inline`/`__inline`/`template` heads), reduced to a declaration (free functions: the body's `{` becomes `;`) or
  dropped (out-of-class members, `A::f() {...}`, which their class declares). `Extraction.to_dict()`. SystemExit when
  no top-level definition is the target.
* `target_identifiers(function) -> {identifier}`: a dump target's source identifier - itself when unmangled, the stem of
  a mangled name (`send__16NetworkSingleTcpFPCUcl` -> `send`, `fn__Fv` -> `fn`), a constructor's/destructor's class
  (`__ct__3BoxFv` -> `Box`, the last `Q` component).

## Invariants and rules

* Textual and conservative: it stands on `lib.cscan` (`function_declarations`, `struct_defs`, `mask_preproc`) and
  `lib.names` (`owner_stem`, `is_mangled`); no C parser.
* The output has exactly the input's line count; preprocessor lines inside a removed body stay.
* Overloads and same-named members of other classes are all kept (harmless: the debugger picks its function by name).

## Lib dependencies

cscan, names.

## Test contract

Tier: fixture - `tools/tests/mwcc-debugger/test_extract.py` (23 checks): a fixture unit keeps the target, every line
number and preprocessor line, stubs the free functions, keeps inline/template definitions, drops an out-of-class
member, refuses a missing target, and the mangled-name rows; the CLI writes the same text.

## Known gaps

An `#if` opened outside a removed body and closed inside it (or the reverse) is not rebalanced; a function-local
`#define` used after the body survives only because preprocessor lines are kept.
